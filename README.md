# TAUREON TITANES - Sistema de Transformación

## Requisitos
- Una cuenta GRATIS en https://render.com
- No necesitas instalar nada en tu PC

## Pasos para tenerlo funcionando (5 minutos)

### 1. Sube los archivos a GitHub (o usa ZIP)
- Ve a https://github.com y crea una cuenta gratis
- Crea un repositorio nuevo llamado "taureon-titanes"
- Sube todos los archivos de esta carpeta

### 2. Crea el servicio en Render.com
- Ve a https://dashboard.render.com
- Haz clic en **"New +"** → **"Web Service"**
- Conecta tu GitHub y selecciona "taureon-titanes"
- Render detectará automáticamente Node.js

### 3. Configura así:
| Campo | Valor |
|---|---|
| Name | `taureon-titanes` |
| Region | `Frankfurt` (o la más cercana) |
| Branch | `main` |
| Build Command | `npm install` |
| Start Command | `node server.js` |
| Plan | **Free** ($0/mes) |

### 4. Haz clic en **"Deploy Web Service"**
- Espera 2-3 minutos a que termine
- Obtendrás una URL como: `https://taureon-titanes.onrender.com`

### 5. ¡Listo!
- Tu panel admin: `https://tu-url.onrender.com/admin/login`
- Usuario: `admin`
- Contraseña: `taureon2026`

Cada Titán accede desde: `https://tu-url.onrender.com/titan/login`

## Desde tu celular
Simplemente abre la URL en Chrome/Safari. Funciona perfecto.
